# Synced Lyric Player

A dynamic, interactive media client built to play audio tracks with fully synchronized lyrics. Developed as a Web Development project by **Jose Mari Aguinaldo**, this application demonstrates advanced DOM manipulation and custom HTML5 Audio API integration.

_(Demo Track: PUP University Hymn)_

## 📖 Overview

Standard media players offer basic playback controls, but this project elevates the user experience by tightly coupling the audio state with the visual interface. It allows users to visually track exactly where they are in a song and intuitively navigate the audio simply by interacting with the text.

## ✨ Features

- **Bi-Directional Synchronization:** Smooth lyric highlighting that automatically progresses in real-time with the audio playback.
- **Interactive Media Controls:** A fully custom audio player featuring a play/pause toggle, interactive progress bar, and real-time playback indicators.
- **Advanced Volume Management:** An intuitive vertical volume slider that smoothly appears on hover and auto-hides after inactivity.
- **Audio Navigation:** Skip forward and backward controls for precise timestamp navigation.
- **Responsive UI:** A fully responsive layout with scalable background styling tailored for various screen sizes.

## 💻 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **APIs:** Native HTML5 Audio API
